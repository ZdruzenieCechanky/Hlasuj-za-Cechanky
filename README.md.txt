
# Hlasuj za Čechánky

Tento repozitár obsahuje súbor, ktorý automaticky presmeruje návštevníka 
na stránku hlasovania Zelené oázy a zvýrazní projekt Čechánky rámikom.

## Ako aktivovať GitHub Pages

1. Prejdi na **Settings → Pages**
2. Source nastav na: **Deploy from branch**
3. Branch: **main**  
   Folder: **/** (root)
4. Klikni **Save**
5. Stránka bude dostupná tu:

https://ZdruzenieCechanky.github.io/Hlasuj-za-Cechanky/hlasuj-za-cechanky.html

Stačí zdieľať tento link na Facebooku.
